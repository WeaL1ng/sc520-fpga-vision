## 2. 关键验证：P1b Logo 位置（原本是唯一未验证项）

### 2.1 问题

P1b 把 Logo ROM 从**组合 case** 改成**同步读 ERAM**（多 1 拍延迟），
并把地址计算提前到 `_1d` 坐标级来吸收这一拍。
**这个对齐原来只是推导，没有任何仿真或上板证据。**

### 2.2 方法（三个互相独立的实现，不依赖任何假设）

| # | 工具 | 做什么 |
|---|---|---|
| ① | **ModelSim** | 编译 `hdmi_mixer` + `logo_rom_eram` + `osd_char_lib` + TB，跑**两次**仿真（`+osd=0` / `+osd=1`），各导出 1280×720 逐像素文本 |
| ② | **ModelSim** | 断言两次 DE 有效像素数**精确 = 921,600**（=1280×720），确认帧完整无丢 |
| ③ | **Python** | 直接从 `logo_pixel.mif` + `logo_palette.vh` 算**期望包围盒**；把两次仿真的**差集**当**实测包围盒**；两者比对 |

**为什么用"两次仿真做差"而不是在 TB 里解码背景**：
`I_osd_en` 只控制 Logo（安路 Logo + 动态文字），状态条与模式数字不受它影响 ——
所以两次运行的**唯一差异就是 OSD 内容**。做差得到的区域是精确的 OSD 覆盖区，
**完全避开了对"背景像素编码"的假设**（我第一版 TB 就是在这里假设错了）。

### 2.3 结果

```
EXPECTED (由 logo_pixel.mif + logo_palette.vh 算出)
  ROM depth              : 13724
  palette colours        : 256
  non-transparent pixels : 6387
  SCREEN bbox (x,y,w,h)  : (7, 34, 146, 94)

MEASURED (两次 ModelSim 仿真逐像素做差)
  run A (+osd=0) pixels  : 921600
  run B (+osd=1) pixels  : 921600
  diffs OUTSIDE window   : 888    (= 安路 CNT 动态文字，在 x=375..575, y=120..145)
  pixels differing IN win: 6293
    of which in palette  : 6293   ← 全部命中调色板颜色，0 个例外
    not in palette       : 0
  MEASURED bbox (x,y,w,h): (7, 34, 146, 94)

COMPARISON
  expected: x=7   y=34   w=146   h=94
  measured: x=7   y=34   w=146   h=94
  delta   : dx=+0  dy=+0  dw=+0  dh=+0
  [PASS] Logo position and size match exactly - no 1-pixel shift
```

**三重自洽**：
1. 原点 **(7,34)** 与裁剪区几何 `LOGO_ROM_X0/Y0 = 7/34` 精确吻合；
2. 尺寸 **146×94** 与裁剪区精确吻合；
3. 窗口内差异像素**全部**是调色板颜色（6293/6293），说明**没有丢失也没有多余**。

⇒ **P1b 的流水线对齐推导正确，Logo 无 1 像素偏移。**

## 3. 独立实现的交叉验证（防"自己验自己"）

本会话刻意让**生成侧**与**校验侧**用不同的代码路径：

| 环节 | 生成侧 | 校验侧 |
|---|---|---|
| ROM 内容 | `tools/gen_logo_rom_v.py`（Python 解析 mif → 写 Verilog case） | 独立 Python 正则从**生成的 Verilog** 反解，与 **mif 源**逐条比对 |
| 调色板 | 同上（从 `logo_palette.vh` 解析） | 另一段正则从 `hdmi_mixer.v` 反解，与 `logo_palette.vh` 逐条比对 |
| Logo 位置 | Verilog 里的行基址累加 + 流水线 | Python 直接由几何参数算期望值；与**仿真输出差集**比对 |
| 时序/资源 | — | **TD P&R 报告**（唯一权威来源，不信任何估算） |

**结果**：
- ROM：`mif 条目 = 13724  ROM case 条目 = 13724`，**不一致条目 = 0**
- 调色板：**256/256 一致**
- 位置：**dx=dy=dw=dh=0**

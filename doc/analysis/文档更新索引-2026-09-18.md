## 3. 本轮最值得注意的几条新增结论

1. **工作区/工具链路径必须纯 ASCII**，且这是**实测踩到的坑**（不是理论风险）。现已全部解决。
2. **基线必须重新标定**：本机工具版本下 **DDR 域从 0.576 ns 回到 2.311 ns**（原文档把"DDR 贴线"列为高风险，可降级）；
   但 **HDMI 像素域从 0.103 ns 掉到 0.006 ns**，**P1（Logo→ERAM + OSD 流水线化）因此更不可跳过**。
3. **`参考IP设计资料文档.zip` 已解包**：内含 PPT slide 19 点名的 `APUG013 UDP 参考设计`、`APUG092 HDMI`、`IPUG012 Soft_FIFO` 等。
   ⚠ 其中 `UG921 MIPI` 与 `IPUG035 DDR` 标注的是 **PH1A 系列**，PH1P 权威手册另有其物（`UG1316`、`IPUG034`、`UG1310`）。
4. **片上 RISC-V MCU 的工具链顾虑作废**：安路官方 **FutureDynasty (FD)** 明确支持 **PH1P35** 的 RISC-V/ARM 工程。
   可把遥测组包 / GPS NMEA 解析 / 命令解析迁到 MCU，**省约 900 LUT + 4 DSP**（算法层仍必须在 FPGA）。
5. **`video_source_test.v` 不是彩条发生器** —— 实测是"视频时序骨架 + 红色渐变图源"（121 行，默认 1920×1080），
   在原例程里是给 **HDMI IP** 灌图的。**可复用它的 `user/valid/last` 时序骨架，图样需自己换。**
   另：该 HDMI 1.4b IP 自带 **`VIDEO_TPG`（默认 Enable，内建测试图）** 与 **EDID 读取接口**。
6. **5 条新架构思路**（详见增量分析文档 §2）：
   A. 在 160×90 缩略图上做 **RLE 单遍连通域**（官方 PPT 点名"连通域"，成本比预想低一个数量级）
   B. 片上 MCU 的**合规切分**（决策层下放、算法层不下放）
   C. **把 DDR 写通路上浪费的 32 bit 变成"像素标签位"**（零额外带宽，让卡通化/检测/运动**同时叠加**而非互斥切换）
   D. **无摄像头开发**（测试图源分层方案）
   E. **区域快门**（一个按键把 DDR 占用降到 6.3%，用于"零争用窗口"实测与低功耗叙事）
